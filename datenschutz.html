‍Cloudfront, Amazon Web Services – Content Delivery Network (CDN)
Auf unserer Webseite kommt das CDN Amazon Cloudfront, ein Dienst der Amazon Web Services EMEA SARL („AWS), zum Einsatz. Ein CDN ist ein Netzwerk aus (weltweit) verteilten Servern, welches in der Lage ist, optimiert Inhalte an Webseitennutzer auszuliefern. Cloudfront verwendet ein globales Netzwerk von Edge-Standorten (kleine Data Center) und regionalen Edge-Caches, die Kopien Ihrer Inhalte zwischenspeichern. Cloudfront stellt dabei sicher, dass die Anforderungen der Nutzer vom nächstgelegenen Edge-Standort erfüllt werden. Als Ergebnis müssen die Anforderungen der Betrachter nur eine kurze Distanz zurücklegen, sodass die Leistung verbessert wird. Dateien, die nicht im Cache der Edge-Standorte und den regionalen Edge-Caches zwischengespeichert werden, hält Cloudfront eine Dauerverbindung mit Ihren Ursprungsservern aufrecht, damit diese Dateien so schnell wie möglich abgerufen werden können. Dadurch wird eine schnellere Ladezeit der Website, eine höhere Ausfallsicherheit und ein erhöhter Schutz vor Datenverlust erreicht. Einige der auf dieser Website eingebundenen Bilder und Videos werden beim Aufruf der Seite von Cloudfront abgerufen. Hierbei werden Informationen über Ihre Nutzung unserer Website an Server von AWS außerhalb der Europäischen Union bzw. des Europäischen Wirtschaftsraumes übertragen und dort gespeichert. Dies erfolgt, sobald sie unsere Internetseite betreten. Empfänger Ihrer Daten ist AWS mit Sitz in den USA. Die USA gelten als datenschutzrechtlich unsicheres Drittland. Hierzu wurde mit AWS ein Vertrag zur Auftragsverarbeitung gemäß Art. 28 DS-GVO geschlossen.
